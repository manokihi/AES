Welcome to the public repository for the AI-Driven Embedded Systems class. The turned-in assignments are in the Assignments
sub-directory. They are organized according to the assignment sequence, e.g. Assignment 1, Assignment 2, etc.
The assignment solutions are mostly provided as Jupyter/Colab notebooks (*.ipynb). For each notebook, there is also a Python
source file (*.py).

Some assignments may also have a presentation and in that case, the presentation is in the Presentation directory in the
assignment sub-directory.
